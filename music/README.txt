PRIV-ESC — MUSIC FOLDER
========================================

Put the finished tracks in this folder. Two naming schemes work:

  title.mp3                 a single track, looped
  track1.mp3, track2.mp3 …  a playlist, played in number order

You can use both: title.mp3 plays first, then track1, track2 and so on.

Each track fades out over its last two seconds, then there is a two second
silence, then the next track starts. After the last one it loops back to the
first.

Sound is off by default. Turn it on in Settings > Sound.

The prompts for the tracks are in
/storage/emulated/0/Documents/priv-esc-music-prompts.txt
